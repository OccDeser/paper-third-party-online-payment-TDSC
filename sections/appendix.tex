\section{Payment Scenarios Illustrations}

To aid in understanding the different third-party online payment scenarios discussed in \ref{sec:payment-scenarios}, we have drawn illustrative diagrams for the three payment scenarios, namely Payment Scenario \Rom{1} (In-app Payment), Payment Scenario \Rom{2} (Mobile Web Payment), and Payment Scenario \Rom{3} (QR Code Payment), as shown in Figures~\ref{fig:inapp_payment}--\ref{fig:qr_code_payment}. 

\begin{figure}[h]
    \centering
    \includegraphics[width=\linewidth]{img/pays1.pdf}
    \caption{Payment Scenario \Rom{1} --- In-app Payment}
    \label{fig:inapp_payment}
\end{figure}

In in-app payment, the workflow can be summarized in the following steps:

\noindent\textbf{Step 1.} The user selects goods and initiates a purchase request at the merchant application.

\noindent\textbf{Step 2.} The merchant frontend communicates with the merchant server to create the order and derive payment-relevant information.

% 正文里有的不用解释。不要用中文引号 ’，后面都一样
\noindent\textbf{Step 3.} Merchant application invokes \emph{PS-App} through the payment provider's SDK.

\noindent\textbf{Step 4.} The user authorizes the payment within \emph{PS-App}, typically by entering a payment password.

\noindent\textbf{Step 5.} \emph{PS-App} submits the payment request to the payment server (\emph{PS-Server}) for validation and execution.

\noindent\textbf{Step 6.} The \emph{PS-Server} performs the funds transfer.

\noindent\textbf{Step 7.} The \emph{PS-Server} sends a callback notification to merchant server.

\begin{figure}[h]
    \centering
    \includegraphics[width=\linewidth]{img/pays2.pdf}
    \caption{Payment Scenario \Rom{2} --- Mobile Web Payment}
    \label{fig:mobile_web_payment}
\end{figure}

% In mobile web payment, the workflow follows Steps 1–7 as described above, except for Step 3, which differs as follows:
In mobile web payment, the workflow is as follows:

\noindent\textbf{Step 1--2.} Same as in-app payment.

\noindent\textbf{Step 3.} The mobile web page triggers \emph{PS-App} via a URL scheme. 
% 应该是web page 通过 URL scheme 启动 PS-App，并传递支付参数。

\noindent\textbf{Step 4-7.} Same as in-app payment.

\begin{figure}[h]
    \centering
    \includegraphics[width=\linewidth]{img/pays3.pdf}
    \caption{Payment Scenario \Rom{3} --- QR Code Payment}
    \label{fig:qr_code_payment}
\end{figure}

In QR code payment, the workflow is as follows:

\noindent\textbf{Step 1--2.} Same as in-app payment.

\noindent\textbf{Step 3.} The merchant web page generates and displays a payment QR code encoding the invocation information, and the user scans the QR code using a mobile device to launch \emph{PS-App}.

\noindent\textbf{Step 4-7.} Same as in-app payment.
